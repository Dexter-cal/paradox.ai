## What is Prob?
Prob (formerly ROB) is an autonomous research organism designed to push the frontier of what can be known. It doesn't just answer questions; it discovers them.

## Key Features
- **Autonomous Discovery Loop:** Hunt for unknowns, hypothesize solutions, and log failures/successes endlessly.
- **Probabilistic Reasoning:** View the world in probability bands, not certainties.
- **Self-Repairing Brain:** Analyzes its own errors and proposes structural fixes.
- **Sovereign Oversight:** Decoupled UI and natural language guardrails give the user full control without limiting the AI's creativity.

## Quick Start
1. **Install:** `pip install -r requirements.txt`
2. **Launch:** `python -m prob.ui.app`
3. **Colab:** Use the `ULTIMATE_COLAB_GUIDE.md` for zero-setup GPU acceleration.
