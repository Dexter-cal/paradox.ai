# Prob AI v4.0.0 | The Autonomous Discovery & Reasoning Engine

## Overview
Prob (also known as ROB) is a unified AI system for autonomous discovery, problem-solving, and continuous learning. It is designed to operate even in the absence of humans, discovering patterns, simulating outcomes, and documenting findings across multiple domains.

---

## Core Architecture

### 1. The Brain (LLM & Reasoning)
- **Model Selector**: Automatically detects hardware (GPU/VRAM) and chooses the best available model (GPT-OSS-20B, Llama-3, Phi-3, etc.). Supports 4-bit/8-bit quantization via `bitsandbytes`.
- **ProbBrain Core**: A wrapper for Hugging Face `transformers` that handles reasoning, multi-step thought tracing, and hypothetical simulation.
- **Consultants (AI Bridge)**: Connects to external OpenAI-compatible APIs to "consult" with other models.

### 2. The Curiosity Engines
- **What-If Engine**: Simulates hypothetical scenarios and ripple effects.
- **Search Engine**: Autonomous web research via DuckDuckGo.
- **Data Library**: Manages datasets from Hugging Face and local uploads.
- **Self-Trainer Engine**: Identifies knowledge gaps, searches for data, and generates training scripts (LoRA/fine-tuning) to improve itself.
- **Model Factory**: Designs and builds new neural network architectures or training loops autonomously.

### 3. Safety & Control
- **Natural Language Guardrails**: Configure system constraints in plain English (e.g., "Do not propose unsafe chemical reactions"). Rules can be toggled or removed entirely via the UI.
- **Honesty Engine**: Evaluates the certainty of responses and flags high-risk or sensitive findings for the **Sensitive Vault**.
- **Human Review Vault**: Holds sensitive discoveries until approved by an authorized evaluator.

### 4. Memory & Documentation
- **Memory Engine**: Persistent JSON-based storage for all Discoveries, Failures, and Notebook entries.
- **Thought Trace**: Logs step-by-step internal reasoning branches.
- **Documentation Engine**: Generates professional PDFs, Markdown reports, CSV datasets, and even full books from stored research.
- **Progress Summarizer**: Provides daily autonomous briefings on the dashboard.

### 5. Interaction
- **Professional Dashboard (Web UI)**: A dark-themed, tabbed interface for research, chat, data management, coding, and system monitoring.
- **CLI Interface**: Full control of Prob via terminal (`python -m prob.cli.main`).
- **Autonomous Loop**: A dedicated script (`prob/scripts/autonomous_loop.py`) for independent, long-running discovery missions.

## Getting Started

### Installation
```bash
pip install flask transformers torch bitsandbytes peft accelerate psutil pynvml requests duckduckgo_search matplotlib
```

### Running the UI
```bash
python -m prob.ui.app
```
Access the dashboard at `http://localhost:5000`.

### Running the Autonomous Loop
```bash
python prob/scripts/autonomous_loop.py
```

### CLI Commands
- `ask "What if fuel prices double?"`
- `whatif "Scenario description"`
- `search "Topic to research"`
- `status` (Shows system health)

## Technical Details

- **Self-Modification**: Prob can rewrite its own code via the `SelfModifierEngine`. It always creates a timestamped backup in `prob/memory/backups/` before applying changes.
- **Sandboxed Execution**: Python code generated by the `CoderEngine` or `ModelFactory` is executed in a controlled environment within `prob/output/`.
- **Knowledge Graph**: Every discovery updates a local JSON relationship graph (`prob/memory/knowledge_graph/graph.json`), allowing Prob to see connections between seemingly unrelated research threads.
